# MyScoutee ⚡

MyScoutee is an experimental Angular UI for a **group-based dating concept**, where matching is based on mutual priorities instead of endless swiping.

The project was largely generated by AI (~500,000 lines) and then partially refactored.

---

## 🌐 Live Demo

👉 [UI Prototype](https://fssrepository.github.io/myscoutee/)

> **Demo image note:** This non-commercial UI prototype loads event and asset
> placeholders from [Lorem Picsum](https://picsum.photos/) (images sourced from
> Unsplash under the [Unsplash License](https://unsplash.com/license)) and
> profile portraits from [Random User](https://randomuser.me/documentation).
> These placeholder URLs were introduced by AI-generated seed code and resolve
> sample images; no specific photo, photographer, or depicted person was
> intentionally selected or endorsed.
> Random User says its portraits were selected from the authorized section of
> UI Faces, but does not state one uniform image license; their provenance must
> therefore be checked before public production use. A standalone server demo
> will instead use separately generated WebP images served from its own MinIO.
